# sism.proofer.tech 모션 설계

B2B 페이지라 움직임은 읽는 순서를 안내하는 데까지만 쓴다. 기본 이징은 power3.out, 등장 거리는 12~36px, 길이는 0.5~1초. 반복 모션은 일러스트 안의 작은 요소에만 둔다. prefers-reduced-motion 이면 전부 끄고 정적 화면을 그대로 보여 준다.

라이브러리: GSAP 3.12.5 + ScrollTrigger(스크롤 연동, 타임라인), anime.js 3.2.2(SVG 도형과 숫자 카운트). cdnjs 로 불러온다.

## 구간별 설계

| 구간 | 트리거 | 모션 |
|---|---|---|
| 히어로 | 로드 | 배경 사진 1.12배에서 1배로 2.4초 줌아웃. 헤더, 영문 라벨, 제목 줄 마스크 리빌(줄마다 0.12초 간격), '내 사업' 그라데이션이 블루에서 그린으로 흐름, 서브 문구와 버튼 순차 등장, 신뢰 띠 4칸 순차 등장 후 '100건+' 숫자 카운트업 |
| 히어로 배경 | 스크롤 scrub | 배경 사진이 화면보다 느리게 내려가는 패럴랙스(yPercent 10) |
| 미니 헤더 | 히어로 끝 통과 | 블러 배경의 고정 헤더가 위에서 내려옴. 하단에 페이지 진행 막대, 현재 보고 있는 섹션 메뉴에 밑줄. 다시 히어로로 올라가면 숨김 |

| 업무 시스템 | 카드 등장 시 | ERP, CRM 약어가 넓은 자간에서 제자리로 모이고 그라데이션이 흐름 |
| 수행 이력 더보기 줄 | 등장 시 | 겹친 원이 왼쪽에서 들어오고 '+' 원이 천천히 숨 쉼 |

## 캔버스와의 관계

Claude Design 캔버스는 보드 높이를 고정해서 그리기 때문에 스크롤 연동 모션을 확인할 수 없다. 모션은 같은 내용을 일반 웹페이지로 옮긴 모션 시안(`모션시안/index.html`, `motion.js`)에서 확인한다. 실제 구현 때는 `motion.js` 를 그대로 옮겨 쓸 수 있게 셀렉터를 섹션 id 기준으로 잡았다.
