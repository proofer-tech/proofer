# IR 소개서 PDF 뷰어 디자인 규격

> 대상: `/docs/introduction-of-proofer` 의 pdf.js 뷰어(본체 31058350, 툴바 37e209a7).
> 구성(무엇을 넣는가)은 요구 565ef1bd 에서 PM 이 정했고, 이 문서는 그것이 어떻게 보이고 어떻게 조작되는지를 정한다.
> 색, 라운드, 그림자, 모션은 모두 `docs/landing-design-system.md` 의 토큰 이름으로 적는다. 이 문서는 hex 값을 새로 만들지 않는다.
> 아이콘은 레포 의존성에 이미 있는 `lucide-react` 에서 고르고, 컴포넌트 이름을 그대로 적는다.

## 1. 배치

뷰어는 `.wrap` 컨테이너(max-width 1160px, 좌우 패딩 24px) 안에서 h1 바로 아래에 놓인다. 뷰어 바깥 틀(이하 "프레임")이 툴바와 쪽 목록을 함께 감싼다.

헤더(`app/components/Header.tsx`)가 `fixed` 이고 높이가 60px 이므로, 툴바의 sticky 기준은 `top: 60px` 이다. 전체 화면에서는 헤더가 없으므로 `top: 0` 이다.

## 2. 툴바 컨트롤

### 2.1 공통 상태

모든 아이콘 버튼은 같은 상태 규칙을 쓴다. 아이콘은 `lucide-react`, 크기 20px, `strokeWidth` 2 이다.

| 상태                     | 배경                  | 아이콘 색             | 기타                                                                                   |
| ------------------------ | --------------------- | --------------------- | -------------------------------------------------------------------------------------- |
| 기본                     | 투명                  | `Gray`                | 라운드 `Small`(9px)                                                                    |
| 호버                     | `Blue Soft`           | `Blue`                | 전환 0.15s, 이징은 디자인 시스템의 reveal 이징                                         |
| 누름(active)             | `Blue Soft`           | `Blue Deep`           |                                                                                        |
| 포커스(`:focus-visible`) | 기본 또는 호버와 같다 | 기본 또는 호버와 같다 | `outline: 2px solid` `Blue`, `outline-offset: 2px`. 마우스 클릭에는 링을 그리지 않는다 |
| 비활성                   | 투명                  | `No Mark`             | `disabled` 속성을 붙이고, 호버와 누름 반응을 끈다. `cursor: default`                   |

크기: 데스크톱 버튼 36 x 36px, 모바일 버튼 44 x 44px(터치 기준).

`prefers-reduced-motion` 에서는 호버 전환을 끈다.

### 2.2 컨트롤별 규격

| 컨트롤          | 아이콘(`lucide-react`)                  | 크기        | 비활성이 되는 조건                                                       | 폭         |
| --------------- | --------------------------------------- | ----------- | ------------------------------------------------------------------------ | ---------- |
| 이전 쪽         | `ChevronLeft`                           | 36px        | 현재 1쪽                                                                 | 데스크톱만 |
| 다음 쪽         | `ChevronRight`                          | 36px        | 현재 마지막 쪽                                                           | 데스크톱만 |
| 쪽 번호 입력    | 없음                                    | 아래 2.3    | 로딩 중                                                                  | 데스크톱만 |
| 전체 쪽 수      | 없음                                    | 아래 2.3    | 해당 없음                                                                | 데스크톱만 |
| 축소            | `ZoomOut`                               | 36px        | 배율 50%                                                                 | 데스크톱만 |
| 배율 표시       | 없음                                    | 아래 2.4    | 해당 없음                                                                | 데스크톱만 |
| 확대            | `ZoomIn`                                | 36px        | 배율 200%                                                                | 데스크톱만 |
| 폭 맞춤         | `MoveHorizontal`                        | 36px        | 이미 폭 맞춤 상태                                                        | 데스크톱만 |
| 다운로드        | `Download`                              | 36px / 44px | PDF 데이터를 아직 받지 못함                                              | 두 폭 모두 |
| 전체 화면       | `Maximize`, 전체 화면 중에는 `Minimize` | 36px / 44px | 해당 없음. Fullscreen API 가 없으면(iOS Safari) 버튼을 렌더링하지 않는다 | 두 폭 모두 |
| 쪽 표시(모바일) | 없음                                    | 아래 2.3    | 해당 없음                                                                | 모바일만   |

로딩 중에는 이전, 다음, 축소, 확대, 폭 맞춤도 비활성이다.

### 2.3 쪽 번호 입력과 전체 쪽 수

- 데스크톱: `[ 3 ] / 16` 형태로 놓는다.
  - 입력칸: 폭 44px, 높이 32px, 배경 `BG`, 테두리 1px `Line`, 라운드 `Small`(9px), 글자 `Body Small`(14.5px) 700, 색 `Ink`, 가운데 정렬, `inputmode="numeric"`.
  - 입력칸 호버: 테두리 `Border Hover`. 포커스: 테두리 `Blue` 와 2.1 의 포커스 링. 비활성: 글자 `No Mark`.
  - 입력칸에 포커스가 들어오면 값 전체를 선택한다. Enter 로 이동하고, 범위 밖이거나 숫자가 아닌 값은 현재 쪽으로 되돌린다. Esc 는 값을 되돌리고 포커스를 뷰어 영역으로 돌린다.
  - `/ 16`: `Body Small`(14.5px) 400, 색 `Gray`, 입력칸과 6px 간격.
- 모바일: 입력칸 없이 `3 / 16` 텍스트만 둔다. `Body Small`(14.5px), 현재 쪽 700 `Ink`, `/ 16` 400 `Gray`.
- 전체 쪽 수는 상수 16 이 아니라 pdf.js 가 읽은 `numPages` 를 쓴다.

### 2.4 배율

- 배율 100% 는 PDF 원본 크기(960pt 를 960 CSS px 로 그린 크기)다. 폭 맞춤은 프레임 안쪽 폭에 맞춘 배율이며, 1440px 데스크톱에서 약 111% 다.
- 확대와 축소는 다음 단계 중 현재 배율 다음 값으로 이동한다: 50, 67, 75, 90, 100, 110, 125, 150, 175, 200 (%). 폭 맞춤 배율이 두 단계 사이에 있으면 바로 다음 단계로 간다.
- 배율 표시: 폭 52px, 가운데 정렬, `Caption / Tag`(12px) 700, 색 `Gray`, 숫자에 `font-variant-numeric: tabular-nums`. 반올림한 정수와 `%` 를 적는다(예: `111%`).
- 확대나 축소 뒤에도 보고 있던 쪽의 같은 위치가 화면에 남아야 한다.

## 3. 상태 화면

### 3.1 로딩

- 쪽 자리: 16:9 자리를 쪽 수만큼 먼저 잡는다. `numPages` 를 아직 모르면 16개를 잡는다. 자리 면은 배경 `BG`, 테두리 1px `Line`, 그림자 없음.
- 첫 쪽 자리 가운데에 진행 표시를 둔다.
  - `LoaderCircle` 24px, 색 `Blue`, 1s 선형 회전. `prefers-reduced-motion` 에서는 회전하지 않는다.
  - 그 아래 10px 에 문구: `소개서를 불러오는 중입니다 (42%)`. `Body Small`(14.5px), 색 `Gray`. 받은 바이트 비율을 정수로 적고, 전체 크기를 모르면 괄호를 빼고 문구만 둔다.
  - 그 아래 12px 에 진행 바: 폭 160px(모바일 120px), 높이 4px, 바탕 `Line`, 채움 그라데이션 `Progress`, 라운드 `Pill`.
- 나머지 쪽 자리는 빈 면으로 둔다(쪽마다 스피너를 두지 않는다).
- 문서를 받은 뒤 아직 그리지 않은 쪽(화면에서 먼 쪽)도 같은 빈 면이다. 화면 근처로 들어와서 그릴 때 깜빡임 없이 canvas 로 바뀐다.
- 툴바는 로딩 중에도 보이고, 2.2 의 로딩 중 비활성 규칙을 따른다. 전체 쪽 수 자리에는 `/ 16` 을 그대로 둔다.

### 3.2 오류

PDF 를 받지 못하면 쪽 자리 목록 대신 프레임 안에 오류 블록 하나를 둔다. 툴바는 숨긴다.

- 블록: 16:9 면 하나, 배경 `BG`, 테두리 1px `Line`, 내용 가운데 정렬, 좌우 안쪽 여백 24px.
- 아이콘: `TriangleAlert` 28px, 원형 배경 `Warn BG` 48px 안에, 아이콘 색 `Warn Text` 의 두 값 중 진한 쪽(`Warn BG` 위 대비 4.56:1).
- 제목(아이콘 아래 14px): `소개서를 불러오지 못했습니다`. `H3`(데스크톱 23px, 모바일 18px) 700, 색 `Ink`.
- 설명(제목 아래 6px): `네트워크 상태를 확인한 뒤 새로고침하거나, PDF 를 새 탭에서 열어 보세요.` `Body Small`(14.5px), 색 `Gray`, max-width 420px.
- 링크(설명 아래 18px): `PDF 새 탭에서 열기` + 오른쪽에 `ExternalLink` 16px. 파란 버튼 모양(배경 `Blue`, 글자 `BG`, 라운드 `Pill`, 패딩 12px 20px, 그림자 `Button Primary`). 호버 배경 `Blue Deep`. 포커스는 2.1 의 링. `target="_blank" rel="noopener noreferrer"`, 주소는 `IR_PDF_URL`.
- 오류 블록 전체에 `role="alert"` 를 붙여 스크린리더가 한 번 읽게 한다.
- 문서는 받았는데 한 쪽만 그리지 못하면 그 쪽 자리에만 `Gray` 색 `Body Small` 문구 `이 쪽을 표시하지 못했습니다` 를 가운데에 둔다. 다른 쪽은 그대로 보인다.

### 3.3 전체 화면

- 대상 요소는 프레임 전체(툴바 포함)다. 진입은 전체 화면 버튼, 나가기는 같은 버튼 또는 Esc(브라우저 기본 동작)다.
- 배경: 프레임 배경을 `Ink` 로 바꾸고, 프레임 테두리와 라운드를 없앤다.
- 툴바: 화면 맨 위에 `top: 0` 으로 붙고, 면과 컨트롤 상태는 평소와 같다(배경 `BG`). 라운드는 0 이다.
- 쪽: 배율을 폭 맞춤으로 다시 계산한다(화면 폭에서 좌우 24px 를 뺀 폭). 쪽 그림자는 끄고 테두리도 끈다(어두운 바탕에서는 경계가 이미 보인다). 쪽 사이 간격은 16px 이다.
- 진입과 나가기 때 보고 있던 쪽을 유지한다.
- 전체 화면 버튼의 아이콘은 `Minimize`, `aria-label` 은 `전체 화면 끝내기` 로 바뀐다. 별도 안내 문구나 토스트는 없다.
- 진입하면 포커스를 뷰어 영역으로 옮겨 바로 키보드로 넘길 수 있게 한다.

### 3.4 그 밖의 상태

| 상태           | 처리                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 빈 상태        | 뷰어에는 항상 같은 PDF 하나가 들어오므로 빈 상태가 없다. `numPages` 가 0 이면 3.2 오류로 처리한다 |
| 0건 결과       | 검색 기능이 없어 해당 없다                                                                        |
| 긴 텍스트 잘림 | 툴바에 가변 텍스트가 없다. 쪽 수가 두 자리를 넘으면 입력칸 폭을 52px 로 늘리고, 줄바꿈하지 않는다 |
| 좁은 폭(320px) | 모바일 배치 그대로, 프레임 폭 272px, 쪽 폭 256px. 툴바 구성은 바뀌지 않는다                       |

## 4. 접근성

### 4.1 `aria-label` 문구

| 요소              | 역할과 속성                                    | `aria-label`                                              |
| ----------------- | ---------------------------------------------- | --------------------------------------------------------- |
| 뷰어 영역(프레임) | `role="region"`, `tabIndex={0}`                | `프루퍼 서비스 소개서 PDF 뷰어`                           |
| 툴바              | `role="toolbar"`                               | `소개서 보기 도구`                                        |
| 이전 쪽           | `button`                                       | `이전 쪽`                                                 |
| 다음 쪽           | `button`                                       | `다음 쪽`                                                 |
| 쪽 번호 입력      | `input`, `inputmode="numeric"`                 | `쪽 번호, 전체 16쪽` (숫자는 `numPages`)                  |
| 축소              | `button`                                       | `축소`                                                    |
| 배율 표시         | `output`, `aria-live="polite"`                 | 라벨 없이 값 `111%` 를 그대로 읽는다                      |
| 확대              | `button`                                       | `확대`                                                    |
| 폭 맞춤           | `button`, 폭 맞춤 상태면 `aria-pressed="true"` | `폭에 맞추기`                                             |
| 다운로드          | `button`                                       | `PDF 다운로드`                                            |
| 전체 화면         | `button`                                       | `전체 화면` / 전체 화면 중 `전체 화면 끝내기`             |
| 쪽 canvas         | `role="img"`                                   | `소개서 16쪽 중 3쪽`                                      |
| 모바일 쪽 표시    | 텍스트                                         | 라벨 없이 `3 / 16` 앞에 시각적으로 숨긴 `현재 쪽` 을 둔다 |

모든 아이콘 버튼의 `title` 은 `aria-label` 과 같은 문구로 두어 마우스 툴팁을 겸한다. 키 단축키가 있는 버튼은 `aria-keyshortcuts` 를 붙인다(이전 `ArrowLeft PageUp`, 다음 `ArrowRight PageDown`, 확대 `+`, 축소 `-`, 폭 맞춤 `0`).

### 4.2 포커스 링

- 모든 조작 요소(버튼, 입력칸, 오류 링크, 뷰어 영역)에 `:focus-visible` 로 `outline: 2px solid` `Blue`, `outline-offset: 2px` 를 그린다.
- 뷰어 영역의 링은 프레임 라운드를 따라가게 `outline-offset: 2px` 를 그대로 쓴다.
- `outline: none` 으로 링을 지우는 스타일은 금지한다.
- `Blue` 링은 `BG` 위 6.29:1, `BG Alt` 위 5.87:1, 전체 화면의 `Ink` 위 3.01:1 이다(비텍스트 기준 3:1 충족).

### 4.3 대비 4.5:1

이 문서가 쓰는 글자와 아이콘 조합의 대비(WCAG 상대 휘도 기준, 직접 계산):

| 전경                 | 배경        | 대비    | 쓰는 자리                      |
| -------------------- | ----------- | ------- | ------------------------------ |
| `Gray`               | `BG`        | 6.18:1  | 기본 아이콘, 설명 문구, `/ 16` |
| `Gray`               | `BG Alt`    | 5.77:1  | 프레임 위 문구                 |
| `Blue`               | `Blue Soft` | 5.62:1  | 호버 아이콘                    |
| `Blue Deep`          | `Blue Soft` | 9.98:1  | 누름 아이콘                    |
| `Ink`                | `BG`        | 18.93:1 | 입력칸 숫자, 오류 제목         |
| `BG`                 | `Blue`      | 6.29:1  | 오류 링크 버튼 글자            |
| `Warn Text`(진한 쪽) | `Warn BG`   | 4.56:1  | 오류 아이콘                    |

- 비활성 아이콘 `No Mark` 는 `BG` 위 1.69:1 이다. WCAG 는 비활성 컨트롤을 대비 기준에서 제외하고, 비활성 여부는 색이 아니라 `disabled` 속성으로도 전달되므로 허용한다.
- 색만으로 의미를 전달하지 않는다: 폭 맞춤의 켜짐 상태는 `aria-pressed` 와 비활성 처리로, 오류는 아이콘과 문구로 함께 전달한다.

### 4.4 키보드 조작

키는 포커스가 뷰어 영역 안(프레임 자신 또는 그 안의 요소)에 있을 때만 처리한다. 페이지의 다른 곳에서는 가로채지 않는다. 처리한 키에만 `preventDefault` 를 건다.

| 키                            | 동작                                                                |
| ----------------------------- | ------------------------------------------------------------------- |
| `ArrowLeft`, `PageUp`         | 이전 쪽                                                             |
| `ArrowRight`, `PageDown`      | 다음 쪽                                                             |
| `+` (`=` 도 같은 키로 받는다) | 확대                                                                |
| `-`                           | 축소                                                                |
| `0`                           | 폭 맞춤                                                             |
| `Tab`                         | 툴바 컨트롤을 왼쪽에서 오른쪽 순서로 지난다. 비활성 버튼은 건너뛴다 |

- 쪽 번호 입력칸에 포커스가 있을 때는 숫자와 화살표를 입력칸이 쓰므로 위 단축키를 처리하지 않는다. Enter 와 Esc 만 2.3 대로 처리한다.
- 쪽 이동은 그 쪽 위쪽 가장자리가 툴바 바로 아래에 오도록 스크롤한다. `prefers-reduced-motion` 이면 즉시 이동하고, 아니면 `scroll-behavior: smooth` 로 이동한다.
- 단축키에 Ctrl, Cmd, Alt 가 함께 눌려 있으면 처리하지 않는다(브라우저 확대 `Cmd +` 를 막지 않기 위해서다).
