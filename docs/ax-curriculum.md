# 프루퍼 AX 서비스 커리큘럼 스펙

프루퍼 주식회사가 기업에 제공하는 AX(AI Transformation) 서비스의 커리큘럼 단일 출처입니다.
랜딩 페이지(`ax.proofer.tech`)가 노출하는 모든 커리큘럼 문구는 이 문서를 근거로 삼습니다.
페이지 구조와 전환 설계는 `docs/ax-landing-spec.md`에 따로 적혀 있습니다.

## 0. 설계 근거

이 커리큘럼은 프루퍼가 직접 설계한 것입니다. 설계할 때 기업 AI 교육 시장에 이미 나와 있는
과정들을 참고 자료로 훑었지만, **그 자료는 프루퍼의 자산이 아니고 프루퍼의 수행 실적도
아닙니다.** 따라서 이 문서의 어떤 항목도 프루퍼의 실적 근거로 쓰지 않고, 참고한 과정의
이름이나 고객사 이름을 이 문서와 랜딩 페이지 어디에도 적지 않습니다.
랜딩 페이지가 신뢰의 근거로 삼는 것은 `docs/ax-landing-spec.md` 2.5절에 따로 정해 두었습니다.

기업이 실제로 필요로 하는 층은 다섯 개로 갈립니다. 세 카테고리는 그 다섯 층을 덮도록 짰습니다.

| 기업이 필요로 하는 층        | 이 커리큘럼에서의 자리 |
| ---------------------------- | ---------------------- |
| 전사 확산 입문               | AX 강의 L1             |
| 직무 심화                    | AX 강의 L2             |
| 파워유저, 에이전트           | AX 강의 L3             |
| 리더, 임원                   | AX 강의 L4             |
| 프로젝트 기반 학습(PBL)      | AX 해커톤              |
| 사내 담당자 양성             | AX 컨설팅 Step 4       |

세 카테고리 전체에 공통으로 넣는 요소는 셋입니다. 카테고리와 무관하게 항상 포함합니다.

1. 보안 수칙 - AI 입력은 곧 외부 전송이라는 원칙, 넣지 않는 자료의 목록, 더미 데이터 원칙.
2. 실습 우위 - 이론 설명 뒤에 반드시 수강생 본인의 업무 자료로 하는 실습이 붙습니다.
3. 결과물 공유 - 실습 산출물을 대시보드에 올리고 피드백을 받는 절차가 마지막에 붙습니다.

## 1. AX 강의

기업 구성원이 AI를 실제 업무에 쓰게 만드는 집합 교육입니다. 네 개 레벨로 나뉘고,
고객사는 한 레벨만 단독으로 열거나 L1에서 L3까지 순차로 전개할 수 있습니다.

### L1. AX 입문 - 전사 확산

- 대상: 직무 무관 전 직원. 한 번도 생성형 AI를 업무에 써 본 적이 없는 인원을 기준으로 설계합니다.
- 분량: 4시간 또는 8시간. 정원 30명에서 40명.
- 도달 목표: 수료 시점에 본인의 반복 업무 세 가지를 AI 워크플로로 옮긴 상태가 됩니다.

| 모듈                    | 시간 | 내용                                                                    |
| ----------------------- | ---- | ----------------------------------------------------------------------- |
| 오프닝                  | 0.5H | 왜 지금 AI인가, 오늘 하루 사용법, 내 반복 업무 3개 적어내기             |
| 생성형 AI 트렌드와 이해 | 0.5H | 모델 지형, 무엇을 할 수 있고 무엇을 못 하는가, 환각의 원리              |
| 프롬프트 설계 4원칙     | 1H   | RCTF 프레임워크(Role, Context, Task, Format), 실패한 프롬프트 고쳐 쓰기 |
| 나만의 업무 AI 만들기   | 1H   | GPTs / Gems / Projects로 반복 업무를 고정 자산으로 만들기               |
| 보안 수칙               | 0.5H | AI 입력은 곧 외부 전송, 절대 넣지 않는 것, 더미 데이터 원칙             |
| 업무 적용 실습과 공유   | 1H   | 본인 업무 자료로 실습, 결과물 업로드, 상호 피드백                       |

8시간 편성일 때 추가하는 모듈: 엑셀 반복 업무 자동화(ChatGPT + VBA, 1H),
리서치 자동화(Deep Research + NotebookLM, 1H), 용도별 AI 도구 지도(0.5H).

### L2. AX 직무 - 직무 심화

- 대상: 직무별 분반. HR, 기획관리, 영업마케팅, 설계기술, 안전품질, 생산, 재무 등으로 엽니다.
- 분량: 2일(16시간). 정원 20명에서 30명.
- 도달 목표: 자기 직무의 실제 산출물 한 종을 AI로 처음부터 끝까지 만들어 냅니다.

| 모듈                        | 시간 | 내용                                                            |
| --------------------------- | ---- | --------------------------------------------------------------- |
| 프롬프트 엔지니어링의 기술  | 1H   | L1 복습을 겸한 심화, 직무 문맥을 프롬프트에 넣는 법             |
| 실전 문서 생성형 AI 활용법  | 1.5H | 보고서, 기획안, 회의록의 초안 생성과 사실 검증                  |
| 엑셀을 코딩 없이 자동화하기 | 1.5H | ChatGPT + VBA로 직무 반복 계산과 서식 작업 자동화               |
| 직무 데이터 분석            | 2H   | 직무 데이터셋으로 문제 정의, 지표 설계, 시각화, 해석            |
| 직무별 심화 문서 처리       | 1.5H | 분반별로 다름. HR은 채용, 평가 문서. 기획관리는 계약, 기성 문서 |
| 직무별 보안 실무 가이드     | 1H   | 분반이 실제로 다루는 민감 정보 기준으로 반출 금지선 확정        |
| 바이브 코딩 체험            | 1H   | 코드를 몰라도 동작하는 화면을 만들어 보는 첫 경험               |
| 개인 MVP 기획 및 개발       | 2H   | 본인 업무 병목 하나를 골라 동작하는 도구로 만들기               |
| 결과물 공유 및 피드백       | 1H   | 시연, 상호 피드백, 현업 적용 계획 확정                          |

부록으로 상시 제공: NotebookLM 활용, Perplexity와 Comet 브라우저,
MCP와 API 이해하기, 실무 데이터 연동 방법, 용도별 AI 도구 확인표.

### L3. AX 파워유저 - 에이전트와 컨텍스트 엔지니어링

- 대상: 부서의 AI 활용을 끌고 갈 인원, 개발 조직, 데이터 담당자. L1 또는 L2 수료를 전제합니다.
- 분량: 2일(16시간). 정원 15명에서 20명. 실습 밀도가 높아 정원을 낮게 잡습니다.
- 도달 목표: 사람이 매번 지시하지 않아도 도는 에이전트 하나를 본인 업무에 배치합니다.

| 모듈                | 시간 | 내용                                                             |
| ------------------- | ---- | ---------------------------------------------------------------- |
| 동작 원리           | 1.5H | 답이 만들어지는 과정, 컨텍스트 윈도우와 토큰, 추론 모델의 차이   |
| 진입점 지도         | 1H   | Chat, Project, Desktop, Code, Cowork를 언제 각각 쓰는가          |
| 컨텍스트 엔지니어링 | 2H   | 프롬프트가 아니라 환경을 설계한다, 요청을 짜는 다섯 칸           |
| 규칙 파일 작성      | 1.5H | CLAUDE.md로 폴더에 규칙을 두기, 용어와 양식과 금지사항 명문화    |
| 검증과 재현성       | 1.5H | 답을 검증하는 3단계, 스스로 검토시키기, 같은 지시 다른 결과 잡기 |
| 에이전트와 스킬     | 2H   | 에이전트 5단계 사이클, 도구 호출, 서브 에이전트, 스킬 제작       |
| 사내 데이터 연결    | 1.5H | MCP와 커넥터로 사내 시스템, 파일, API 붙이기와 그 경계           |
| 종합 실습           | 3H   | 주간 보고 에이전트, 점검 일지 정리 에이전트 등 실제 업무 과제    |
| 배포와 운영         | 2H   | 동료에게 넘기기, 오류 확인과 수정, 유지보수 부담 줄이기          |

### L4. AX 리더 - 임원, 리더

- 대상: 임원, 팀장, 의사결정 라인. 도구 숙련이 아니라 판단 기준을 만드는 자리입니다.
- 분량: 3시간. 정원 제한 없음.
- 도달 목표: 우리 조직에서 무엇부터 AI로 바꿀지, 그 판단을 스스로 내립니다.

| 모듈                     | 시간 | 내용                                                       |
| ------------------------ | ---- | ---------------------------------------------------------- |
| 지금 무엇이 가능해졌는가 | 0.5H | 데모 중심. 경쟁사와 동종업계가 실제로 하고 있는 것         |
| 도입 의사결정 프레임     | 1H   | 어떤 업무가 후보인가, 효과 추정, 실패하는 도입의 공통점    |
| 리스크 판단              | 0.5H | 보안, 법무, 환각, 저작권을 리더가 어디까지 알아야 하는가   |
| 조직 설계                | 0.5H | AI 담당자와 챔피언을 어디에 두는가, 성과를 무엇으로 재는가 |
| 리더가 물어야 할 질문    | 0.5H | 실무진 보고를 검증하는 질문 목록을 손에 쥐고 나갑니다      |

### 공통 운영 규격

- 강사 1인에 운영 매니저 1인. 정원 30명을 넘으면 보조 튜터를 1인 추가합니다.
- 교안은 온라인 문서로 제공하고 수료 후 열람 기간을 둡니다.
- 실습 대시보드에 결과물을 올리고 질문과 만족도 조사를 같은 자리에서 받습니다.
- 교육 기간 동안 유료 AI 계정을 프루퍼가 제공합니다. 고객사 계정 사용도 가능합니다.
- 사전 환경 세팅 가이드를 교육 3영업일 전에 배포하고, 당일 접속 점검을 진행합니다.
- 과정 종료 후 만족도와 현업 적용률을 담은 결과 리포트를 제출합니다.

## 2. AX 해커톤

교육이 실제 성과로 이어지지 않는 문제를 푸는 프로그램입니다. 부서의 실제 병목을 과제로 걸고,
팀이 동작하는 결과물을 만들어 내는 데까지 끌고 갑니다. 총 5단계이고 전후 준비까지 포함해
약 6주에서 8주가 걸립니다.

### Phase 0. 과제 발굴 (2주, 비집합)

- 부서별 업무 병목 수집. 설문과 담당자 인터뷰로 후보 과제를 모읍니다.
- 과제 심사. 해커톤 기간 안에 동작까지 갈 수 있는 크기인지, 데이터가 있는지를 기준으로 거릅니다.
- 팀 편성. 팀당 3명에서 5명, 현업과 IT 인력을 섞습니다.
- 환경 세팅 가이드 배포와 사전 점검.
- 산출물: 확정 과제 목록, 팀 편성표, 심사 기준표.

### Phase 1. 킥오프 (0.5일)

- 문제 정의. 무엇이 얼마나 불편한지를 숫자로 적습니다.
- 기획 3단 - PRD, SPEC, PLAN을 팀별로 작성합니다.
- 심사 기준 공개. 무엇으로 평가받는지 먼저 알고 시작합니다.
- 산출물: 팀별 PRD 문서.

### Phase 2. 빌드 (1일에서 2일)

- 바이브 코딩으로 동작하는 최소 결과물을 만듭니다.
- 멘토링. 강사 1인이 최대 4팀을 담당하고 순회합니다.
- 중간 체크포인트 2회. 범위가 커진 팀을 잘라 주는 것이 이 자리의 목적입니다.
- 산출물: 동작하는 결과물, 중간 점검 기록.

### Phase 3. 데모데이 (0.5일)

- 팀당 시연 5분, 질의 3분.
- 심사 배점 - 문제 적합성 30, 동작 완성도 30, 확장 가능성 20, 발표 20.
- 심사위원은 프루퍼 강사와 고객사 임원이 함께 구성합니다.
- 산출물: 데모 영상, 발표 자료, 심사 결과.

### Phase 4. 이관 (2주, 비집합)

- 상위 과제의 사내 배포 가능성을 판정합니다. 보안, 유지보수, 담당자를 함께 봅니다.
- 이관 리포트 작성. 무엇을 누가 이어받는지까지 적습니다.
- 다음 파일럿 후보 선정.
- 산출물: 이관 리포트, 후속 과제 목록.

### 운영 규격

- 권장 규모: 4팀에서 10팀. 10팀을 넘으면 멘토를 추가하거나 분리 개최합니다.
- 선행 조건: 참가자 다수가 AX 강의 L1 이상을 수료한 상태여야 합니다. 미수료 인원이 많으면
  Phase 1 앞에 L1 압축 과정 4시간을 붙입니다.
- 시상. 고객사가 상금과 시상 등급을 정하고 프루퍼가 심사와 진행을 맡습니다.

## 3. AX 컨설팅

개인의 도구 숙련이 아니라 조직의 체계를 바꾸는 일입니다. 진단에서 시작해 사내 인력이
스스로 굴릴 수 있는 상태까지 넘겨주는 것으로 끝납니다. 총 4단계, 3개월에서 6개월입니다.

### Step 1. 진단 (2주에서 4주)

- 업무 인벤토리 작성. 부서별로 무슨 일을 얼마나 하는지를 시간 단위로 훑습니다.
- 병목 매핑과 AI 적용 가능성 점수화. 빈도, 규칙성, 데이터 유무, 리스크 네 축으로 봅니다.
- 현행 도구와 보안 정책 점검. 이미 산 도구가 왜 안 쓰이는지를 확인합니다.
- 경영진 인터뷰. 무엇을 성과로 볼 것인지를 이 자리에서 확정합니다.
- 산출물: 진단 리포트, 과제 후보 풀, 적용 가능성 점수표.

### Step 2. 로드맵 (2주)

- 3개년 AX 로드맵. 연차별 목표와 도달 상태를 적습니다.
- 우선순위 과제 선정. 효과와 난이도로 4분면에 놓고 1년차 과제를 확정합니다.
- 조직 설계. AI 담당자와 부서 챔피언의 자리, 권한, 평가 방법을 정합니다.
- 도구 스택 선정. 무엇을 사고 무엇을 안 사는지, 계정 정책과 비용 구조까지 정합니다.
- 보안 가이드라인 초안. 반출 금지 데이터 기준과 승인 절차를 문서로 만듭니다.
- 산출물: AX 로드맵, 과제 우선순위표, 조직 설계안, 도구 스택 제안서, 보안 가이드라인.

### Step 3. 파일럿 (6주에서 12주)

- 1개에서 2개 부서를 골라 실제 자동화를 구축합니다. 프루퍼가 직접 만듭니다.
- 효과 측정. 도입 전후의 소요 시간, 처리 건수, 오류율을 같은 기준으로 잽니다.
- 사내 자산화. 표준 프롬프트, 규칙 파일, 에이전트를 사내에서 재사용할 형태로 남깁니다.
- 산출물: 동작하는 자동화, 효과 측정 리포트, 사내 표준 자산 묶음.

### Step 4. 내재화 (상시)

- 사내 강사 양성. 프루퍼 교안으로 사내 인력이 직접 가르칠 수 있게 만듭니다.
- AI 담당자 양성. 동료의 막힘을 진단하고 부서 배포용 자산을 만드는 역할을 훈련합니다.
- 교안과 자산 이관. 사내 포털에 두고 갱신 주체를 정합니다.
- 분기 점검. 확산 지표를 함께 보고 다음 과제를 정합니다.
- 산출물: 사내 강사 인증, 담당자 운영 매뉴얼, 분기 점검 리포트.

### 운영 규격

- 프루퍼 투입: 컨설턴트 1인이 상주 없이 주 1회에서 2회 방문, 파일럿 단계에서 개발 인력 합류.
- 고객사 요청 사항: 부서별 담당자 지정, 데이터 접근 승인, 경영진 정기 보고 자리.
- 강의, 해커톤과의 관계: 로드맵이 확정되면 실행 수단으로 두 가지를 끌어다 씁니다.
  컨설팅 계약 안에서 강의와 해커톤을 함께 운영하는 것이 표준 형태입니다.

## 4. 세 카테고리를 잇는 도입 경로

고객사가 어디서 시작하든 같은 종착점으로 갑니다. 랜딩 페이지는 이 경로를 보여주고,
방문자가 자기 위치를 찾게 만드는 것을 목적으로 삼습니다.

```
AX 강의 (쓸 줄 알게 만든다)
   -> AX 해커톤 (실제 성과를 만들어 본다)
      -> AX 컨설팅 (조직이 스스로 굴린다)
```

역방향도 성립합니다. 컨설팅으로 시작한 고객사는 로드맵 안에서 강의와 해커톤을 실행 수단으로 씁니다.

| 고객사의 현재 상태             | 첫 제안                       |
| ------------------------------ | ----------------------------- |
| AI를 아직 안 쓴다              | AX 강의 L1 전사 확산          |
| 도구는 샀는데 안 쓴다          | AX 강의 L2 직무 심화 + 해커톤 |
| 교육은 했는데 성과가 안 보인다 | AX 해커톤                     |
| 전사 체계가 필요하다           | AX 컨설팅                     |
| 사내에서 자체 운영하고 싶다    | AX 컨설팅 Step 4 내재화       |
