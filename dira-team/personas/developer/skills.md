## 스킬

이 페르소나가 쓰는 스킬이다. 해당하는 일이면 먼저 이걸 쓴다.

- `ponytail` — Forces the laziest solution that actually works, simplest, shortest, most minimal. Channels a senior dev who has seen everything: question whether the task needs to exist at all (YAGNI), reach for the standard library before custom code, native platform features before dependencies, one line before fifty. Supports intensity levels: lite, full (default), ultra. Use on ANY coding task: writing, adding, refactoring, fixing, reviewing, or designing code, and choosing libraries or dependencies. Also use whenever the user says "ponytail", "be lazy", "lazy mode", "simplest solution", "minimal solution", "yagni", "do less", or "shortest path", or complains about over-engineering, bloat, boilerplate, or unnecessary dependencies. Do NOT use for non-coding requests (general knowledge, prose, translation, summaries, recipes).
- `devex-review` — Live developer experience audit. (gstack)
- `ship` — Ship workflow: detect + merge base branch, run tests, review diff, bump VERSION, update CHANGELOG, commit, push, create PR. (gstack)
- `im-korean` — 한국어 원고를 특정 저자의 문체로 쓰거나 고치고, AI 티와 슬롭을 탐지해 제거하는 통합 스킬. 초안은 무색 규율(부사·헛기침 도입·강조 목발·메타 해설·모호한 단언·무생물 주어·행위자 은폐 수동·문장 파편·3항목 리듬 금지)로 쓰고, 그 위에 매체별 보이스를 도색 허가표 범위 안에서 입힌다. 책·에세이·블로그·뉴스레터·기사·소셜 게시물·댓글·콜드메일·DM·보고서까지 매체별 톤을 정하고, 실제 교정 이력에서 뽑은 금지 규칙을 적용한 뒤, 번역투·기계적 병렬·관용구·피동 남용·접속사 남발·리듬 균일성 등 A~M 카테고리 패턴을 잡아 사실·수치·고유명사·인용을 건드리지 않고 문체만 다시 쓴다. 어미 축약형 원형화, 어체 혼용 금지, 번역투 치환, 광의 고유어를 협의 한자어로 가르는 어휘 정밀도 규약을 전 매체 공통으로 적용한다. 생략된 문장 성분과 조사·어미를 복원해 전보체를 없애고, 관형격 '의' 연쇄와 비유어의 일반 어휘 대체를 되돌리는 명료성 규약을 원고와 보고 문장 양쪽에 적용한다. 트리거 - \"내 문체로 써줘\", \"이 글 내 스타일로 고쳐줘\", \"소셜 게시물 초안\", \"뉴스레터 써줘\", \"콜드메일 써줘\", \"AI 티 없애줘\", \"슬롭 빼줘\", \"stop slop\", \"AI 문투 제거\", \"사람이 쓴 것처럼 윤문\", \"번역투 제거\", \"GPT 문체 제거\", \"말 뭉뚱그리지 말고 정확하게\", \"휴머나이저\", \"humanize Korean\", \"말이 잘려서 나온다\", \"조사가 빠졌다\", \"전보체 같다\", \"명확한 한국어로\". 후속 - \"특정 카테고리만 다시\", \"윤문 강도 조정\", \"이 문단만\", \"2차 윤문\", \"도색 빼고 무색으로\". 단순 맞춤법 교정은 직접 처리, 번역은 번역 스킬. 한국어 원고 전용.
