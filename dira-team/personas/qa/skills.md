## 스킬

이 페르소나가 쓰는 스킬이다. 해당하는 일이면 먼저 이걸 쓴다.

- `qa` — Systematically QA test a web application and fix bugs found. (gstack)
- `browse` — Fast headless browser for QA testing and site dogfooding. (gstack)
- `open-gstack-browser` — Launch GStack Browser — AI-controlled Chromium with the sidebar extension baked in.
- `watch` — Watch a video (URL or local path). Downloads with yt-dlp, extracts auto-scaled frames with ffmpeg, pulls the transcript from captions (or Whisper API fallback), and hands the result to Claude so it can answer questions about what's in the video.
